\hypertarget{md_theory_autotoc_md35}{}\doxysubsubsection{\texorpdfstring{Recursive Definitions}{Recursive Definitions}}\label{md_theory_autotoc_md35}

\begin{DoxyItemize}
\item {\bfseries{Recursive definitions}} contain formulas where each term is based on one or more preceding terms
\begin{DoxyItemize}
\item Many recursive numerical formulas have something called a {\bfseries{closed form}}, which is a closed expression that doesn\textquotesingle{}t involve computing each term in the formula/sequence (similar to a summation)
\begin{DoxyItemize}
\item Deriving this closed form is an act known as {\bfseries{unrolling}}, where we substitute a recursive definition into itself until there is an explicit pattern suggesting the closed form expression
\end{DoxyItemize}
\end{DoxyItemize}
\end{DoxyItemize}

For example with the expression, \$\$ \textbackslash{}begin\{aligned\} T(n) \&= 2T(n − 1) + 3 \textbackslash{} \&= 2(2T(n − 2) + 3) + 3 \textbackslash{} \&= 2(2(2T(n − 3) + 3) + 3) + 3 \textbackslash{} \&= 2\texorpdfstring{$^\wedge$}{\string^}3T(n − 3) + 2\texorpdfstring{$^\wedge$}{\string^}2 · 3 + 2 · 3 + 3 \textbackslash{} \&= 2\texorpdfstring{$^\wedge$}{\string^}4T(n − 4) + 2\texorpdfstring{$^\wedge$}{\string^}3 · 3 + 2\texorpdfstring{$^\wedge$}{\string^}2 · 3 + 2 · 3 + 3 \textbackslash{} \&\textbackslash{}dots \textbackslash{} \&= 2\texorpdfstring{$^\wedge$}{\string^}kT(n − k) + 2\texorpdfstring{$^\wedge$}{\string^}\{k−1\} · 3 + \textbackslash{}dots+ 2\texorpdfstring{$^\wedge$}{\string^}2 · 3 + 2 · 3 + 3 \textbackslash{}end\{aligned\} \$\$

we can use summation notation to represent the \$k\texorpdfstring{$^\wedge$}{\string^}\{th\}\$ unrolling step, where \$\$ \textbackslash{}begin\{aligned\} \&= 2\texorpdfstring{$^\wedge$}{\string^}kT(n − k) + 2\texorpdfstring{$^\wedge$}{\string^}k−1 · 3 + . . . + 2\texorpdfstring{$^\wedge$}{\string^}2 · 3 + 2 · 3 + 3 \textbackslash{} \&=2\texorpdfstring{$^\wedge$}{\string^}kT(n − k) + 3(2\texorpdfstring{$^\wedge$}{\string^}k-\/1 + \textbackslash{}dots + 2\texorpdfstring{$^\wedge$}{\string^}2 + 2 + 1) \textbackslash{} \&=2\texorpdfstring{$^\wedge$}{\string^}kT(n -\/ k) + 3\textbackslash{}sum\texorpdfstring{$^\wedge$}{\string^}\{k-\/1\}\+\_\+\{i = 0\}(2\texorpdfstring{$^\wedge$}{\string^}i) \textbackslash{}end\{aligned\} \$\$

The input of function \$\+T\$ hits the base case when \$n -\/ k = 1\$, or when \$k = n -\/ 1\$. Recall that \$\+T(1) = 1\$ and substituting \$n-\/1\$ value for \$k\$ gives

\$\$ \textbackslash{}begin\{aligned\} T(n) \&= 2\texorpdfstring{$^\wedge$}{\string^}kT(n -\/ k) + 3\textbackslash{}sum\+\_\+\{i = 0\}\texorpdfstring{$^\wedge$}{\string^}\{k = 1\}(2\texorpdfstring{$^\wedge$}{\string^}i) \textbackslash{} \&=2\texorpdfstring{$^\wedge$}{\string^}\{n -\/ 1\}T(1) + 3\textbackslash{}sum\+\_\+\{i = 0\}\texorpdfstring{$^\wedge$}{\string^}\{n-\/2\}(2\texorpdfstring{$^\wedge$}{\string^}i) \textbackslash{} \&=2\texorpdfstring{$^\wedge$}{\string^}\{n -\/ 1\} + 3\textbackslash{}sum\+\_\+\{k = 0\}\texorpdfstring{$^\wedge$}{\string^}\{n -\/ 2\}(2\texorpdfstring{$^\wedge$}{\string^}k) \textbackslash{} \&=2\texorpdfstring{$^\wedge$}{\string^}\{n -\/ 1\} + 3(2\texorpdfstring{$^\wedge$}{\string^}\{n -\/ 1\} -\/ 1) = 4(2\texorpdfstring{$^\wedge$}{\string^}\{n -\/ 1\}) -\/ 3 = 2\texorpdfstring{$^\wedge$}{\string^}\{n + 1\} -\/ 3 \textbackslash{}end\{aligned\} \$\$

therefore making the closed form for function \$\+T\$, \$2\texorpdfstring{$^\wedge$}{\string^}\{n + 1\} -\/ 3\$


\begin{DoxyEnumerate}
\item Given that \$\+T(0) = 5\$, find the closed form solution of \$\$ T(n) = T(n -\/ 1) + 2 \$\$
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item Unroll the first couple of terms

\$\$ \textbackslash{}begin\{aligned\} T(n) \&= T(n -\/ 1) + 2 \textbackslash{} \&= (T(n -\/ 2) + 2) + 2 \textbackslash{} \&= ((T(n -\/ 3) + 2) + 2) + 2 \textbackslash{} \&\textbackslash{}dots \textbackslash{} \&= T(n -\/ k) + 2k \textbackslash{}end\{aligned\} \$\$
\item where \$k = n\$ and \$\+T(n) = T(0) + 2n = 5 + 2n\$
\item Recall that \$\+T(0)\$ can represent any sort of numeric value, where in this case is \$5\$. This numeric value of \$5\$ is known as the {\bfseries{base case}} and \$2n\$ is known as the {\bfseries{recursive case}}
\end{DoxyItemize}
\begin{DoxyEnumerate}
\item Given that \$\+T(1) = 3\$, Find the closed form solution of \$\$ T(n) = 2T(\textbackslash{}frac\{n\}\{2\}) + n \$\$
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item Unroll the first couple terms of the sequence \$\$ \textbackslash{}begin\{aligned\} T(n) \&= 2T(\textbackslash{}frac\{n\}\{2\}) + n \textbackslash{} \&= 2(2T(\textbackslash{}frac\{n\}\{4\}) + \textbackslash{}frac\{n\}\{2\}) + n = 4T(\textbackslash{}frac\{n\}\{4\}) + 2n \textbackslash{} \&= 2(2(2T(\textbackslash{}frac\{n\}\{8\}) + \textbackslash{}frac\{n\}\{4\}) + n) + n = 8T(\textbackslash{}frac\{n\}\{8\}) + 3n\textbackslash{} \&\textbackslash{}dots \textbackslash{} \&= 2\texorpdfstring{$^\wedge$}{\string^}kT(\textbackslash{}frac\{n\}\{2\texorpdfstring{$^\wedge$}{\string^}k\}) + kn \textbackslash{}end\{aligned\} \$\$
\item where \$\textbackslash{}frac\{n\}\{2\texorpdfstring{$^\wedge$}{\string^}k\} = 1 \textbackslash{}rightarrow n = 2\texorpdfstring{$^\wedge$}{\string^}k \textbackslash{}rightarrow k = \textbackslash{}log\+\_\+2n\$ and \$\$ \textbackslash{}begin\{aligned\} T(n) \&= 2\texorpdfstring{$^\wedge$}{\string^}\{\textbackslash{}log\+\_\+2n\} \textbackslash{}cdot T(1) + n \textbackslash{}cdot \textbackslash{}log\+\_\+2n \textbackslash{} \&= n \textbackslash{}cdot T(1) + n\textbackslash{}log\+\_\+2n \textbackslash{} \&= 3n + n\textbackslash{}log\+\_\+2n \textbackslash{}end\{aligned\} \$\$
\end{DoxyItemize}\hypertarget{md_theory_autotoc_md36}{}\doxysubsubsection{\texorpdfstring{Proofs by Induction}{Proofs by Induction}}\label{md_theory_autotoc_md36}
{\bfseries{Induction}} is a technique used to prove recursive definitions/ formulas, indicating that it does match its respective closed form solution
\begin{DoxyItemize}
\item Includes a {\bfseries{base case}}, {\bfseries{inductive hypothesis}}, and {\bfseries{inductive step}}
\begin{DoxyItemize}
\item {\bfseries{Base Case}} -\/ The starting point, where you prove that it holds true for the smallest value, typically \$n = 0\$ or \$n = 1\$
\item {\bfseries{Inductive Hypothesis}} -\/ A assumption that the statement being proven is true for some value \$k\$
\item {\bfseries{Inductive Step}} -\/ Prove the inductive hypothesis with the next step \$k + 1\$
\end{DoxyItemize}
\end{DoxyItemize}
\begin{DoxyEnumerate}
\item Prove that \$1 + 2 + 3 + \textbackslash{}dots + n = \textbackslash{}frac\{n(n + 1)\}\{2\}\$ for \$n = 1\$
\begin{DoxyItemize}
\item Let \$n = 1\$, then \$\textbackslash{}frac\{1(1 + 1)\}\{2\} = 1\$, where \$1 = 1\$ (both sides are equal)
\item Assume the formula holds true for \$k \textbackslash{}geq 1\$, where \$1 + 2 + 3 + \textbackslash{}dots + k = \textbackslash{}frac\{k(k + 1)\}\{2\}\$
\item Prove the inductive hypothesis from b. for \$k + 1\$, the next recurring step \$\$ \textbackslash{}begin\{aligned\} 1 + 2 + \textbackslash{}dots + k + (k + 1) \&= \textbackslash{}frac\{(k + 1)(k + 2)\}\{2\} \textbackslash{} (1 + 2 + \textbackslash{}dots + k) + (k + 1) \&= \textbackslash{}frac\{(k)(k + 1)\}\{2\} + (k + 1) \textbackslash{} \textbackslash{}frac\{k(k + 1) + 2(k + 1)\}\{2\} \&= \textbackslash{}frac\{(k + 2)(k + 1)\}\{2\} \textbackslash{}end\{aligned\} \$\$ where the inductive step does indeed hold
\end{DoxyItemize}
\item Prove \$2\texorpdfstring{$^\wedge$}{\string^}n \textbackslash{}geq n + 1\$
\begin{DoxyItemize}
\item Check if true for \$n = 0\$ \$\$ \textbackslash{}begin\{aligned\} 2\texorpdfstring{$^\wedge$}{\string^}0 \&\textbackslash{}geq 0 + 1 \textbackslash{} 1 \&\textbackslash{}geq 1 \textbackslash{}end\{aligned\} \$\$ {\bfseries{The base case does hold}}
\item Assume the statement holds for \$n = k\$, where \$\$ 2\texorpdfstring{$^\wedge$}{\string^}k \textbackslash{}geq k + 1 \$\$
\item Using this assumption, prove it holds for \$n = k + 1\$ \$\$ \textbackslash{}begin\{aligned\} \&2\texorpdfstring{$^\wedge$}{\string^}\{k + 1\} \textbackslash{}geq (k + 1) + 1 \textbackslash{} \&2\texorpdfstring{$^\wedge$}{\string^}\{k + 1\} \textbackslash{}geq k + 2 \textbackslash{} \&2\texorpdfstring{$^\wedge$}{\string^}k \textbackslash{}cdot 2 \textbackslash{}geq 2(k + 1) \textbackslash{}geq k + 2 \textbackslash{}end\{aligned\} \$\$
\end{DoxyItemize}
\end{DoxyEnumerate}\hypertarget{md_theory_autotoc_md37}{}\doxysubsubsection{\texorpdfstring{Big-\/O}{Big-\/O}}\label{md_theory_autotoc_md37}

\hypertarget{md_theory_autotoc_md39}{}\doxysubsubsection{\texorpdfstring{Graphs}{Graphs}}\label{md_theory_autotoc_md39}
Graphs consist of a set of nodes (points/vertices), \$\+V\$, and a set of edges, \$\+E\$, where the graph is commonly referred to as a pair of sets \$(\+V, E)\$.

Each edge in \$\+E\$ joints two nodes in \$\+V\$, where two nodes connected by an edge are {\bfseries{adjacent}} or {\bfseries{neighbors}}

Edges can have direction, where graphs with these edges are known as {\bfseries{directed graphs}}. This is useful when discussing relations between vertices with contexts to their edges. In contrast, edges that can be traversed in both directions are known as {\bfseries{undirected graphs}}\hypertarget{md_theory_autotoc_md40}{}\doxysubsubsubsection{\texorpdfstring{Additional Graph terminology}{Additional Graph terminology}}\label{md_theory_autotoc_md40}

\begin{DoxyItemize}
\item {\bfseries{Loops}} -\/ a node where an edge connects to itself
\item {\bfseries{Multiple Edges}} -\/ two nodes are connected by multiple edges
\item {\bfseries{Complete Graphs}} -\/ Graphs where each node is connected to every other node. They have \$\textbackslash{}frac\{n(n -\/ 1)\}\{2\}\$ edges
\item {\bfseries{Walks}} -\/ A sequence of nodes and edges, where each edge connects the node before and after it and nodes and edges can repeat
\item {\bfseries{Paths}} -\/ Walks that {\bfseries{cannot repeat nodes and edges}}
\item {\bfseries{Cycles}} -\/ A path that {\bfseries{starts}} and {\bfseries{ends}} at the same
\begin{DoxyItemize}
\item {\bfseries{Cyclic Graphs}} consist of graphs where nodes are connected in a cycle (non cyclic graphs are called {\bfseries{acyclic}}
\end{DoxyItemize}
\item {\bfseries{Wheels}} -\/ Cycle Graphs where there exists a {\bfseries{single central node}} that connects to every other node in the cycle graph
\end{DoxyItemize}

{\bfseries{Subgraphs}} -\/ A smaller graph made from a subset of vertices and edges of a bigger graph

A graph is {\bfseries{simple}} if it does not contain {\bfseries{loops}} or {\bfseries{multiple edges}}\hypertarget{md_theory_autotoc_md41}{}\doxysubsubsubsection{\texorpdfstring{Degree}{Degree}}\label{md_theory_autotoc_md41}
The degree of a node \$v\$, notated as \$deg(v)\$, is the number of edges that are connected to \$v\$. Loops count {\bfseries{twice}} towards the degree of a node.

Each edge contributes to two degrees of a node. Therefore, the {\bfseries{sum of the degrees of all nodes in a graph}} is {\bfseries{twice}} the number of edges, which can be mathematically expressed as

\$\$ \textbackslash{}sum\+\_\+\{v \textbackslash{}in V\}deg(v) = 2\texorpdfstring{$\vert$}{|}\+E\texorpdfstring{$\vert$}{|} \$\$

or

\$\$ \textbackslash{}sum\+\_\+\{k = 1\}\texorpdfstring{$^\wedge$}{\string^}nv\+\_\+k \textbackslash{}in Vdeg(v) = 2\texorpdfstring{$\vert$}{|}\+E\texorpdfstring{$\vert$}{|} \$\$

This is known as the {\bfseries{Handshaking Theorem}}\hypertarget{md_theory_autotoc_md42}{}\doxysubsubsubsection{\texorpdfstring{Isomorphism}{Isomorphism}}\label{md_theory_autotoc_md42}
Isomorphism exists when two graphs have the same structure, albeit the drawings may be different

Two graphs, \$\+G\+\_\+1\$ and \$\+G\+\_\+2\$ are isomorphic when there exists a bijection of \$\$ f \+: V\+\_\+1 \textbackslash{}rightarrow V\+\_\+2 \$\$

Or simply,
\begin{DoxyItemize}
\item The two graphs must have the same number of nodes and the same number of edges
\item For any node degree \$k\$, the two graphs must have the same number of nodes of degree \$k\$. For example, they must have the same number of nodes with degree \$3\$
\item Given a subgraph of \$\+G\+\_\+1\$, that subgraph must also exist in \$\+G\+\_\+2\$
\end{DoxyItemize}\hypertarget{md_theory_autotoc_md43}{}\doxysubsubsubsection{\texorpdfstring{Connectivity}{Connectivity}}\label{md_theory_autotoc_md43}
A graph is {\bfseries{connected}} when there exists a walk between every pair of nodes in \$\+G\$, or simply you can get from {\bfseries{any node to any other node}}

Sometimes removing an edge from a connected graph will completely lose its connectivity. We refer to such edge as a {\bfseries{cut edge}} when if removed, the graph would be disconnected. Similarly, a {\bfseries{cut vertex}} exists when removing such

An {\bfseries{Euler Circuit}} exists when there is a closed walk (circuit) that uses every edge of the graph once. This can only occur when {\bfseries{all degrees of the nodes are even}}

This is because in order to complete the circuit, you must leave each node that you enter. This means that the graph is {\bfseries{connected}} and therefore exists a closed walk that uses every edge of the graph once.\hypertarget{md_theory_autotoc_md44}{}\doxysubsubsubsection{\texorpdfstring{Graph Coloring}{Graph Coloring}}\label{md_theory_autotoc_md44}
Graph coloring is a {\bfseries{technique}} used to assign colors to a node of a graph, where two adjacent vertices {\bfseries{cannot}} share the same color

{\bfseries{Graph Coloring Steps}}
\begin{DoxyEnumerate}
\item Let node, \$v\+\_\+1\$, be the node with the {\bfseries{greatest degree}}
\item Select a color and color {\bfseries{all non neighboring nodes}} to \$v\+\_\+1\$ (i.\+e. an edge does not connect \$v\+\_\+1\$ and another node)
\item Repeat steps 1 and 2 for all non-\/colored nodes until {\bfseries{all nodes in the graph are colored}}
\end{DoxyEnumerate}

The number of colors it takes to color a graph, is known as the {\bfseries{chromatic number}}, mathematically notated as \$\textbackslash{}chi(G)\$\hypertarget{md_theory_autotoc_md45}{}\doxysubsubsubsection{\texorpdfstring{Bipartite Graphs}{Bipartite Graphs}}\label{md_theory_autotoc_md45}
A graph, \$G = (V, E)\$ is {\bfseries{bipartite}}, such that \$\+V\$ can be split into two non-\/overlapping subsets \$\+V\+\_\+1\$ and \$\+V\+\_\+2\$, where every edge connects to an element of \$\+V\+\_\+1\$ in \$\+V\+\_\+2\$.

What this simply means is that {\bfseries{a graph can only be bipartite when its}} \$\textbackslash{}chi(G) = 2\$. This means that a graph can only be colored with {\bfseries{two colors}}\hypertarget{md_theory_autotoc_md46}{}\doxysubsubsection{\texorpdfstring{Trees}{Trees}}\label{md_theory_autotoc_md46}
{\bfseries{Trees}} are undirected graphs with a special node called the {\bfseries{root}}, where every node is connected to the root via one exact {\bfseries{path}}

They are also {\bfseries{acyclic}}, {\bfseries{connected}}, and have \$n\$ {\bfseries{vertices}} with \$n -\/ 1\$ {\bfseries{edges}}\hypertarget{md_theory_autotoc_md47}{}\doxysubsubsubsection{\texorpdfstring{Tree Vocabulary}{Tree Vocabulary}}\label{md_theory_autotoc_md47}

\begin{DoxyItemize}
\item {\bfseries{Parent}} -\/ A node that is directly above another node in a tree
\item {\bfseries{Child}} -\/ A node that is directly below another node in a tree
\item {\bfseries{Sibling}} -\/ Nodes that {\bfseries{share the same parent}}
\item {\bfseries{Leaf}} -\/ A node that has no children
\item {\bfseries{Internal}} -\/ A node that has at least one child
\item {\bfseries{Level}} -\/ The number of edges from the {\bfseries{root}} to the node (the root has a level of \$0\$)
\item {\bfseries{Height}} -\/ The longest path from a node to a leaf (in terms of edges)
\item {\bfseries{Ancestor}} -\/ The ancestor of a node is one that lies on the path from the root to such node
\item {\bfseries{Descendant}} -\/ The descendant of a node is one that lies on the path from such node to a leaf node
\end{DoxyItemize}\hypertarget{md_theory_autotoc_md48}{}\doxysubsubsubsection{\texorpdfstring{m-\/ary Trees}{m-\/ary Trees}}\label{md_theory_autotoc_md48}
\$m\$-\/ary trees are trees that can have at most \$m\$ children. A common type of tree is a {\bfseries{Binary Search Tree}}, where each node has at most \$2\$ children.
\begin{DoxyItemize}
\item {\bfseries{Full}} trees exist when each node has either \$0\$ or \$m\$ children
\item {\bfseries{Complete}} trees exist when all levels are completely filled, except for the lowest one, which is filled from the left
\begin{DoxyItemize}
\item A tree is {\bfseries{full}} and {\bfseries{complete}} when the whole bottom level is fully populated with leaves
\end{DoxyItemize}
\item {\bfseries{Balanced}} trees exist when the heights of its left and right subtrees {\bfseries{differ by at most}} \$1\$
\end{DoxyItemize}

There are \$mi + 1\$ nodes total in a \$m\$-\/ary tree. This means a binary tree has \$2i + 1\$ nodes total.\hypertarget{md_theory_autotoc_md49}{}\doxysubsubsubsection{\texorpdfstring{Height and number of nodes}{Height and number of nodes}}\label{md_theory_autotoc_md49}
There is no exact formula to find the number of nodes and leaves in an \$m\$-\/ary tree. This is because some trees are more bushier (have more children) than others.

However, there are some patterns {\bfseries{(assuming that a given tree is binary)}}
\begin{DoxyItemize}
\item The number of nodes are maximized when a tree, with height \$h\$, is full and complete is \$2\texorpdfstring{$^\wedge$}{\string^}h\$
\begin{DoxyItemize}
\item where the number of nodes at level \$\+L\$ are \$2\texorpdfstring{$^\wedge$}{\string^}L\$ and the total nodes are \$\textbackslash{}sum\texorpdfstring{$^\wedge$}{\string^}h\+\_\+\{L=0\} 2\texorpdfstring{$^\wedge$}{\string^}L\$, with a closed form of \$2\texorpdfstring{$^\wedge$}{\string^}\{h + 1\} -\/ 1\$ 
\end{DoxyItemize}
\end{DoxyItemize}
