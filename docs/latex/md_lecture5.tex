Continuing off of \doxysectlink{md_lecture4}{lecture 4}{0} about a {\ttfamily std\+::vector} implementation in C++, we defined the following things


\begin{DoxyItemize}
\item {\ttfamily data} -\/ a contiguous chunk of memory allocated for our custom implemented {\ttfamily std\+::vector} or {\ttfamily \doxylink{class_array_list}{Array\+List}}
\begin{DoxyItemize}
\item This will be allocated onto the heap, where we get a returned generic type pointer that points to this buffer/chunk of contiguous memory
\end{DoxyItemize}
\item {\ttfamily size} -\/ a generic type pointer that points to the area in memory where data is filled up
\item {\ttfamily capacity} -\/ a generic type pointer that points to the end of the allocated chunk of memory
\end{DoxyItemize}

Our helper {\ttfamily add\+Space()} function must add data to the end of the allocated chunk of memory. However, this causes issues when the allocated chunk of memory is full with data. Recall that this occurs when {\ttfamily size == capacity}.
\begin{DoxyItemize}
\item To solve this problem, we simply need to allocate a new buffer with a bigger capacity and then copy over the previous buffer\textquotesingle{}s data along with the respective pointers to the buffer including {\ttfamily data}, {\ttfamily size}, and {\ttfamily capacity}
\end{DoxyItemize}

We will come back to this {\ttfamily add\+Space()} helper function, but for now we will talk about the main public function that will use {\ttfamily add\+Space()} called {\ttfamily push\+Back()}, which is one very common function in a {\ttfamily std\+::vector}! Recall, that it simply inserts an element at the end of the list

The algorithm for {\ttfamily push\+Back()} becomes simple with our helper {\ttfamily add\+Space()} function


\begin{DoxyEnumerate}
\item Check if {\ttfamily size == capacity}. If so, then call helper function {\ttfamily add\+Space()} to add more space into the function
\item Then, deallocate the {\ttfamily size} pointer and set it equal to the new {\ttfamily data} parameter variable
\begin{DoxyItemize}
\item we do this because this is how we place the given element at the end of the current end of the buffer ~\newline

\item Remember that {\ttfamily size} tracks the end of filled data in the buffer and {\ttfamily capacity} tracks the end of the entire buffer!
\end{DoxyItemize}
\item Add 1 to the {\ttfamily size} pointer to set the pointer to the new current end of the buffer
\end{DoxyEnumerate}
