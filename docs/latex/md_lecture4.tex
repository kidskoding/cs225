\mbox{[}\mbox{[}Lecture 3 -\/ Lists and \doxylink{class_list}{List} ADT\mbox{]}\mbox{]} covered two main capabilities that our \doxylink{class_list}{List} ADT must have, an {\ttfamily insert\+At\+Front} function which inserts a {\ttfamily \doxylink{struct_list_node}{List\+Node}} at the front/head of the {\ttfamily Linked\+List} and a {\ttfamily find} function which finds a {\ttfamily \doxylink{struct_list_node}{List\+Node}} by a given {\ttfamily index}

We will continue our discussion with the next function, {\ttfamily insert}. This is a generic function which will insert data into the {\ttfamily \doxylink{class_list}{List}} at a given index. Recall that this algorithm is done in three steps


\begin{DoxyEnumerate}
\item Call {\ttfamily find} to find the {\ttfamily \doxylink{struct_list_node}{List\+Node}} at the given index
\begin{DoxyEnumerate}
\item Recall that {\ttfamily find} returns a reference of a pointer to a {\ttfamily \doxylink{struct_list_node}{List\+Node}}, written as a type {\ttfamily List\+Node\texorpdfstring{$\ast$}{*}\&}
\end{DoxyEnumerate}
\end{DoxyEnumerate}

Allocate the given data onto the heap
\begin{DoxyEnumerate}
\item Returned pointer should not be a reference pointer! Make just a regular pointer
\item Recall that a reference pointer refers to an existing pointer! There is no existing pointer here, we make a new one when allocating onto the heap
\end{DoxyEnumerate}

Make the newly created node point to the found {\ttfamily \doxylink{struct_list_node}{List\+Node}} at the given index
\begin{DoxyEnumerate}
\item Set the node found at the given index\textquotesingle{}s pointer to the newly created node
\end{DoxyEnumerate}

The algorithm for this is once again simple


\begin{DoxyEnumerate}
\item Find the {\ttfamily \doxylink{struct_list_node}{List\+Node}} at the given index, with our helper {\ttfamily find} function, lets call it {\ttfamily to\+Remove}
\item Create a {\ttfamily temp} {\ttfamily \doxylink{struct_list_node}{List\+Node}} containing the {\ttfamily \doxylink{struct_list_node}{List\+Node}} to be removed, lets call it {\ttfamily temp}
\item Create a variable containing {\ttfamily temp}\textquotesingle{}s {\ttfamily data}, can call this {\ttfamily val}
\item Set to\+Remove to the next {\ttfamily \doxylink{struct_list_node}{List\+Node}} in the {\ttfamily \doxylink{class_list}{List}}
\item delete the {\ttfamily temp} {\ttfamily \doxylink{struct_list_node}{List\+Node}} from memory ({\ttfamily temp} was what was removed)
\item return {\ttfamily val}
\end{DoxyEnumerate}

{\bfseries{A couple things about this algorithm}}
\begin{DoxyItemize}
\item You need a pointer to the node you\textquotesingle{}re removing so you can later delete it, which is what we call {\ttfamily to\+Remove}
\item Creates a copy pointer to the node being removed called {\ttfamily temp}. We keep a separate reference so that we can return its data in the function
\begin{DoxyItemize}
\item Without {\ttfamily temp}, once {\ttfamily to\+Remove = to\+Remove-\/\texorpdfstring{$>$}{>}next}, the previous node that {\ttfamily to\+Remove} stored is now lost
\item We need the original node that was stored in {\ttfamily to\+Remove} in order to be able to return the data that was removed from the {\ttfamily \doxylink{class_list}{List}}, which is why we store it in {\ttfamily temp!}
\end{DoxyItemize}
\item {\ttfamily }delete temp{\ttfamily , ensures the memory allocated to }temp{\ttfamily  is freed. We do this call because we know that the }\doxylink{class_list}{List}{\ttfamily  no longer needs this }temp{\ttfamily  }\doxylink{struct_list_node}{List\+Node}{\ttfamily  (\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}}List\`{} no longer needs to track it!\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*})
\end{DoxyItemize}
