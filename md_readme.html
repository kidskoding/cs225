CS 225 - Introduction

All references/notes are compiled in Doxygen. View here!

CS 225 - Covers the fundamental data structures (list, stack, queue, tree, etc.) and their implementations using C++ and object oriented programming along with an introductory analysis to algorithms

🚨 Prereqs - Must have credit in both CS 173/MATH 213 (Discrete Math) and CS 128 (Introduction to Computer Science II in C++)

🚨 ECE Students - Electrical/Computer Engineering (ECE) students may substitute CS 128 credit for ECE 220 (Intro to Computing Systems), as both earn the same credit

As stated in the prereqs, a strong knowledge in C++ is required to be successful in this course! In other words, please ensure you have a solid grasp in CS 128/ECE 220 course material. Please see Course Info and Resources below for more info

Background

This course is crucial as it provides the foundation for writing efficient software, a skill highly sought after companies like Google, Amazon, and Meta. Mastery in this course will open pathways into working at such companies as they and many other employers rigorously evaluate your skill in writing software before prior to hiring you as a software developer.

Grading

  • 36% - Programming Assignments (MPs) (each MP is worth 6%)
  • 12% - Laboratory Assignments (each Lab is worth 10%)
  • 36% - Exams/Midterms (each Midterm is worth 6%)
  • 16% - Final Exam
